# Credits & asset licenses

- **Card faces and backs** — original work for this project. Faces are
  rendered with CSS and standard Unicode suit symbols (♠ ♥ ♦ ♣,
  U+2660–U+2663); backs are original generative SVG tile patterns authored
  inline as data URIs. No third-party imagery. Public domain card design
  conventions (ranks, suits, pip layouts) only.
- **Sound effects** — synthesized at runtime with the Web Audio API
  (oscillators and noise buffers); no recorded or third-party audio.
- **Favicon** — original inline SVG created for this project.
- **Game rules** — Klondike Solitaire is a traditional public-domain card
  game; mechanics are not subject to copyright. No code, art, sounds, or
  trademarks from any existing solitaire product were copied or referenced.
- **Fonts** — system font stack only; no bundled fonts.

Third-party software (build-time / runtime libraries) is listed in
`package.json` and covered by its respective MIT licenses (Astro, Tailwind
CSS, Vitest, TypeScript).
