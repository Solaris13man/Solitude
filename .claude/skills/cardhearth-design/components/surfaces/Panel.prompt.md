The on-felt surface primitive — translucent dark fill + hairline border. Build trust strips, daily heroes, calendars and instruction panels from it.

```jsx
<Panel tone="gold" pad="lg">
  <strong>No guessing</strong> Every Sudoku is solvable by pure logic — guaranteed.
</Panel>
```

- `tone`: `fill` (default), `soft`, `gold` (gold-veiled border for featured), `glass`.
- Never use an opaque background on the felt — Panels stay translucent so they read on any felt color.
